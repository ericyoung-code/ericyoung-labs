# Splunk-style Log Parser Toolkit

This tool ingests log files (specifically those generated by the ICS Sensor Simulator) and performs basic anomaly detection and statistical analysis.

## Features
- **Traffic Summary**: Counts requests per Source IP.
- **Function Code Usage**: Breaks down which commands are being sent.
- **Anomaly Detection**: Flags specific "High Risk" Modbus function codes (e.g., Write Multiple Coils/Registers) as suspicious activity.

## Quick Start
To use this tool, run the log parser:

```bash
# Analyze a log file
python lab_runner.py log-parser --input traffic.log
```
